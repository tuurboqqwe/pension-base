# Учёт пенсионеров

Учебное WPF-приложение для производственной практики (ПМ.02, ПМ.03).
Все записи о пенсионерах в базе вымышленные.

## Что нужно

- Visual Studio 2019 (16.8 или новее) с компонентом «Разработка классических приложений .NET»
- SQL Server Express LocalDB (ставится вместе с Visual Studio)
- .NET Framework 4.8

## Запуск

1. Открыть `PensionBase.sln`.
2. Нажать F5.
3. При первом запуске программа сама создаст базу `PensionBase` и заполнит её тестовыми данными.
4. В окне входа нажать «Регистрация», создать пользователя и войти.

Строка подключения лежит в `App.config`. Скрипт базы: `Database/create_database.sql`.

## Структура

| Папка | Что внутри |
|---|---|
| `Database` | SQL-скрипт создания базы и тестовых данных |
| `Models` | Классы данных |
| `Data` | Подключение к базе и запросы |
| `Views` | Окна программы |

## Ветки

- `main` стабильная версия
- `develop` текущая разработка, вливается в `main` после проверки
